NYC Heat Risk Mitigation Planning - User Manual

Overview

This user manual explains how city planners can use the web application to explore heat risk, mitigation resources, 2D layers, 3D views, and shadow tools.

Quick Start Guide

  1. Open the web application.
  2. Use the layer control panel to turn on HVI.
  3. Apply the high-risk HVI filter.
  4. Turn on drinking fountains and the walking distance buffer.
  5. Compare uncovered high-risk areas with existing mitigation resources.
